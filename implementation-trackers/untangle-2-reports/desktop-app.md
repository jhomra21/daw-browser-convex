# Untangle step 2: apps/desktop

Scope: `apps/desktop/**` excluding `out/` (build output). About 30.1K lines including tests, about 17K non-test. All line numbers are current HEAD.

## 1. Area summary

- `main.ts` (2878 lines) is the Electron main process. It is a god-module: window and lifecycle, the local control socket (`startSocket`/`handleSocket`, :795-1133), `registerIpc` (:1135-2427, about 1300 lines of inline `ipcMain.handle` closures), startup wiring (:2613-2869), quit flow, permission and CSP handlers, and module-level mutable state (`window_`, `generation`, `audioHostSupervisor`, `pluginCatalogStore`, `vst3WorkerPath`, ...).
- `preload.ts` (728) is the contextBridge. It mirrors `main.ts` handler-by-handler: one `ipcRenderer.invoke` per main handler, with its own copy of some zod schemas.
- `audio-host.ts` (3169) holds three things: the wire encoders for the native control protocol (:189-540), the offline renderer (`renderNativeOffline`, :831-1223), and `createNativeAudioHostSupervisor` (:1467-3157, a roughly 1700-line closure). It also holds the frame decoders inline (:1630-2073), duplicating the idea of `native-host-frame-decoders.ts`.
- `native-request-broker.ts` is the single-slot request queue and watchdog. `native-host-frame-decoders.ts` has six decoders.
- VST3: `native-vst3-coordinator.ts` (attachment ledger and delta planning), `native-vst3-editor-session.ts` (isolated editor supervisors), `native-vst3-host-events.ts`, `vst3-preflight.ts`, `vst3-insertion-preflight.ts`, `vst3-attachment.ts`, `vst3-scanner.ts`, `plugin-catalog.ts` (864), `native-vst-project-bindings.ts`.
- Files and recording: `file-capabilities.ts` (1287) with `native-file-capability-helper.ts` and `native/file-capability-helper.c`; `recording-spool.ts`, `recording-session-owner.ts`, `recording-start-diagnostic.ts`, `recording-ipc-diagnostics.ts`.
- Release and packaging: `forge.config.ts`, `release.config.ts`, `native-release-artifacts.ts`, `generate-native-release-manifest.ts`, `scripts/run-{forge,local,release}.ts`.
- Acceptance and benchmark hooks living in product code: `ae08-evidence.ts`, `benchmark-*.ts`, `quiet-renderer-telemetry.ts`.
- Dependencies in: `@daw-browser/desktop-protocol`, `audio-engine/native-host-wire`, `plugin-host-protocol`, `audio-core-contract`, `control`.
- Dependencies out (bad direction, see Needless links): `../../src/lib/...` and `../../src/types/desktop-bridge`.
- Git evidence (last 400 commits touching the area, 141 commits): `main.ts` 70, `audio-host.ts` 45, `preload.ts` 32, `native-vst3-coordinator.ts` 30.
- Top co-change pairs: `main.ts`+`preload.ts` 29, `audio-host.ts`+`main.ts` 24, `main.ts`+`native-vst3-coordinator.ts` 21, `main.ts`+`native-session-bridge.test.ts` 20, `audio-host.ts`+`preload.ts` 16.
- Outside the area, the same commits touch: `packages/audio-engine/src` 502, `src/lib/desktop` 242, `packages/desktop-protocol/src` 98, `src/types/desktop-bridge.ts` 24.
- Effect-kind duplication: I found no copy of the effect-kind list in `apps/desktop` (rg for reverb/compressor/eq/limiter etc. matched only build output under `out/`). The cross-cutting owner does not need anything from this area.

## 3. Candidate root fixes

1. **Declare each native session operation once.** A table in `packages/desktop-protocol` (or an `ipc/` module) of `{channel, envelope schema, supervisor method, reply shape}` from which main registers handlers, preload builds `invoke` wrappers, and `DesktopBridge` derives its types. The ~20 inline handlers in main.ts:1679-2314 and 30 preload members disappear. Resolves: `main.ts`/`preload.ts` hidden link (high), `registerNativeSessionBytes/Control` duplication, preload reply-type duplicates, `NativeAudioHostSupervisor` interface duplication (derive from the table), channel-import lists. Risk: medium. The security guards (`audioHostAllowed`, transaction token checks, `transaction.generation/senderId` on commit/rollback) must stay per-operation; the stream channels (`transactionToken` absent for stop/teardown) are exceptions that must be expressed in the table.
2. **One `rendererSenderPolicy(event, {mainFrame, privileged, platform})`** replacing the six guard variants. Resolves the six `*Allowed` helpers, :1195, :1234, native-session-access.ts. Risk: low-medium; preserve the current stricter/looser differences deliberately, listing each as an option in code.
3. **Split `main.ts` by owner, not by layer.** Modules: `control-socket` (socket, auth, request/export/import scope tracking, one `RequestScopes` class with a single `release(scope)` path); `renderer-session` (generation, pending map, invalidation with a registered list of per-generation cleanups instead of the hand-enumerated list at :597-630); `audio-session` (host, lifecycle, listeners returning one `dispose`); `window` (createWindow, permissions, protocol). Resolves: module-level lets, six listener globals, quit flags, export/import duplication (:987-1073, :1200-1222), `applyRendererInvalidation` enumeration. Risk: high, because quit and recovery ordering are load-bearing (`prepareQuit` order at :2566-2575). Move code first, then change.
4. **Shared limits and patterns module** in `packages/desktop-protocol` (`maxVstStateBytes`, `maxSerializedPlanBytes`, `sha256HexSchema`, `uuidSchema`, `requestIdSchema`, `unsigned32Schema`, `unsigned64Max`) imported by main, preload, audio-host, coordinator, plugin-catalog, recording-spool and the native-side constants. Resolves: all duplicated literals in Hidden links. Risk: low; values must stay byte-identical (512 KiB, 1 MiB, 1_048_560).
5. **Move the wire layer out of `audio-host.ts`**: encoders, one frame router keyed by frame type with a decoder table, offline renderer reusing the broker, supervisor as a thin lifecycle owner. Resolves: 230-line `if` chain, decoder triplication, duplicate process-lifecycle in offline renderer, worker-notification number table, the `readUInt32BE(8)` repeats. Risk: high (protocol behavior must be byte-for-byte same); `audio-host.test.ts` (99 tests, 3227 lines) is the safety net and should be run unchanged.
6. **Make the desktop app not import from `src/`.** Move `native-instrument-budget-policy`, `desktop-audio-lifecycle`, `recording-delivery-trace`, and the bridge types into `packages/desktop-protocol` (or a new `packages/desktop-bridge`), imported by both sides. Resolves all five `../../src` imports plus the matching test imports. Risk: low (type and pure-function moves).
7. **Environment flags registry** (`env.ts` returning a typed object parsed once: `evidenceDir`, `benchmarkHeartbeat`, `benchmarkSab`, `diagnosticsTrace`, `recordingStartDiagnostic`, artifact path overrides). Resolves the 10-file env reads and the preload argv/side-channel. Risk: low; preload needs its own (sandboxed) read.
8. **Gate acceptance/benchmark hooks behind one `Observer` object** passed once to the supervisor/coordinator instead of `HostEvidence` plus `ae08WorkerEnvironment` plus benchmark telemetry plus diagnostics trace. Or move them to a build-time-removed module. Resolves: evidence parameters across 5 production modules, `diagnostics.snapshot.v2` special cases, `acceptance` bridge member. Risk: medium; acceptance reports depend on current event names.
9. **Single artifact descriptor** (name, resource path, dev-path env var, build target) shared by `main.ts` startup, `vst3-scanner.ts`, `vst3-preflight.ts`, `audio-host.ts`, `release.config.ts`, `forge.config.ts`, `generate-native-release-manifest.ts`. Resolves: artifact name literals, three twin path resolvers, dev vs packaged branching at main.ts:2619-2643. Risk: low-medium; release tests (`release.config.test.ts`, `forge.config.test.ts`) cover it.
10. **A named `bestEffort(promise, reason)` helper** that logs once (or counts) instead of 25 ad-hoc swallow forms. Resolves the swallowed-exception list. Risk: low, but each site's "must not throw" semantic needs to be kept.
11. **Delete or demote test-only seams** (`schedule`/`kill`/`spawnHost` injections via a test factory in a test helper rather than product options; unexport helpers; remove `runAudioHostDiagnostic`, `runTransaction`, `waitForRecordingOutcome` if confirmed). Resolves most of Surplus. Risk: low-medium (tests that rely on them must be rewritten against behavior).
