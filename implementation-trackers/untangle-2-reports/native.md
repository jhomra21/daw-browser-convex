# native/** untangle report (step 2: list only)

## 1. Area summary
- native/audio-core: portable C/C++ DSP core (audio_core.h 1475 lines, audio_core.cpp 10964 lines) built twice: native static lib and Wasm (wasm_entry.cpp). Owns processors, instruments, graph, paged assets. Generated header generated/processor_contract_generated.h comes from packages/audio-core-contract/scripts/generate-contract.ts.
- native/audio-host-macos: CoreAudio host process. main.cpp (1210) is the stdin/stdout frame loop and codec; src/audio-host.cpp (6500) is the god-module with transport, graph revisions, assets, VST attach, schedule, recording, diagnostics; recording-spool.cpp; coreaudio-hal.mm; acceptance-*.h (evidence/observer/tap, env DAW_AE08_EVIDENCE_DIR).
- native/plugin-host: VST3 worker/scanner/supervisor (worker-*.cpp, vst3-worker.cpp 1413) plus a generated header (plugin-host-contract-generated.h) from native/audio-core/scripts/generate-cross-language-contracts.ts.
- Peers in TS: packages/desktop-protocol/src/native-audio-host.ts (constants, ControlType table), packages/audio-engine/src/native-host-wire.ts (graph/event encoders), apps/desktop/audio-host.ts + native-host-frame-decoders.ts (decoders), packages/plugin-host-protocol, packages/audio-core-contract/src/index.ts (instrument state encoders).
- Two generator systems exist already (audio-core-contract and native/audio-core/scripts). Everything else crossing the C++/TS boundary is hand-copied with no check.
- Tests: audio_core_test.cpp 11392 lines (452 assert), audio_host_test.cpp 6985 (1821 assert), worker_supervisor_test.cpp 1031. Bun tests in native/** are source-text greps.
- Git: 400 commits window. 67 commits touched audio-host-macos src/include; 19 also touched apps/desktop/audio-host.ts, 15 packages/desktop-protocol/src/native-audio-host.ts, 16 packages/audio-engine/src/native-host-wire.ts, 17 apps/desktop/audio-host.test.ts. That is roughly 25 to 28 percent of host changes forcing a TS edit with no tie between them.

## 3. Candidate root fixes
1. One wire-contract source of truth for the audio host protocol (all of: protocol version, magic, artifact id, ControlType table, status/enum tables, limits, header sizes, capability bits, struct layouts). Extend the existing generate-cross-language-contracts.ts pattern: a single TS module in packages/desktop-protocol (it already owns most constants) generates native/audio-host-macos/include/daw/audio_host_protocol_generated.h, and the TS decoders use the same tables (readonly maps number to name). Replace the ternary chains in audio-host.ts/native-host-frame-decoders.ts with lookups. Resolves: protocol version, ControlType, limits, mapped ranges mismatch, magic, artifact id, capabilities, readiness/rejected/revision/notification/patch enums, schedule header sizes. Risk: medium; behaviour must stay identical, wire bytes unchanged (compare generated header to current values; keep --check in test-native.sh). Do the mapped-range 256 vs 4096 decision first.
2. Describe fixed-layout records (diagnostics, hello, meter, spectrum, schedule progress, recording status) as field lists with offset and type, generating both C++ writers/readers and TS decoders; removes literal offsets (headerBytes + 88). Risk: higher (large codec rewrite), do after 1. Resolves the binary-layout item.
3. Instrument wire: generate audio_core_instrument_wire.h and the TS encoders in audio-core-contract from one field table; static_assert the wire byte sizes (156, 88, 80, 60); replace `kind == N` with DAW_AUDIO_INSTRUMENT_KIND_*. Resolves instrument wire, kind literal and kGranularStateWireBytes items. Risk: medium (audio state bytes must not change; existing C++/TS round-trip tests catch drift).
4. Generate DAW_AUDIO_PROCESSOR_KIND_* from the same contract (drop the hand enum in audio_core.h:368-384) or static_assert each hand value equals its generated _ID. Resolves processor-kind copy. Risk: low.
5. Make the generated header set a single command (one package script, one --check wired into both contract.test.ts and test-native.sh) and move the generator out of native/ so native/ does not import packages/*/src; resolves two-generator-homes and the native-to-package source dependency. Risk: low.
6. Split audio-host.cpp and audio_core.cpp by responsibility (codec, transport, graph revisions, assets, vst, recording, meters; processors one file per kind), and replace in-file DAW_AUDIO_HOST_TEST_* hooks with injected interfaces so one source compiles to one object. Resolves god-module, test-hook and 4-variant compile items. Risk: high (realtime paths; realtime_callback_guard markers must follow code; do not mix with behaviour change).
7. One shared max-sample-rate / max-frames constant set in the generated header for host, worker supervisor and VST worker. Resolves the 384'000 and 8'192 copies. Risk: low.
