# Untangle pass 2: decision log (whole codebase, with Comments and Tests)

Base: `anti-slop-update` (stacked on #64). Problem lists with file:line evidence: `implementation-trackers/untangle-2-reports/*.md` (11 surveys, about 520 items). Each fix below names the problems it resolves by report and item. Rules for every batch: behavior unchanged (bugs fixed only when a structural fix removes them, each named in the commit), one concern per commit, tests stay green per directory, lint 0/0, typecheck no new errors, FAST-CERT green (re-anchor mutation arms with an anchor-mode rebase record when hot files move), packaged app smoke at the end of high-risk batches.

## Fixes, in execution order

### B1. Delete what nothing uses (Surplus)
Dead exports, test-only exports and their tests, dead UI (nav-user, sidebar, badge, avatar, separator, sheet, skeleton), the extensions project-actions surface, the plugin-host control-frame protocol and external-plugins bridge experiment, about 40 dead Convex functions, dead worker constants, dead engine methods, `runAudioHostDiagnostic` / `runTransaction` / `waitForRecordingOutcome` if still unused, and the knip `ignoreIssues`/`ignoreFiles` entries that hid them. Verify each with rg across src, packages, apps, convex, api, tools, native, including string and dynamic references. Public Convex function names: only delete those with no caller in src/apps/tools/api.
- components R8, src-lib-core 10, src-lib-subsystems 6, control-packages 7, convex-api 3 (dead part), audio-engine 8, desktop-app 11, hooks-routes 8, cross-cutting Surplus.

### B2. Layering: everything depends on what changes less
Move shared types and models down (models out of `src/components` into `src/lib`; lib-owned types out of hooks and context; desktop bridge types, native instrument budget policy, desktop audio lifecycle and recording delivery trace into `packages/desktop-protocol`), so lib never imports components or hooks, hooks never import components, and apps/desktop never imports src. Then enforce it with oxlint `no-restricted-imports` overrides per directory.
- cross-cutting Needless links (13-area cycle in src, 4 lib->components, 7 lib->hooks, 13 hooks->components, 5 apps/desktop->src), components R6/R9, src-lib-core 7/11, src-lib-subsystems 9, hooks-routes 6, desktop-app 6, src-lib-desktop 5 (test fakes out of product folders).

### B3. One registry per kind vocabulary
`packages/shared` owns each kind tuple once (effects, instruments, owned processors) with per-kind traits (label, default params, normalizer, sidechain capability, runtime class, latency/tail, layout rule, portable/native support, persistence operation, history form). Every other copy derives from it: Convex validators, control schemas and planner, local control, undo, normalization, snapshots, presets, device catalog, UI views, engine chain/timing/layout/capabilities, native-built-in parameter mapper. Native `DAW_AUDIO_PROCESSOR_KIND_*` and instrument kind ids are generated by the existing cross-language generator (or static_asserted). Each step first adds a test that the derived list equals the old literal list.
- cross-cutting §3 table (about 30 copies), src-lib-core 1, src-lib-desktop 1, src-lib-subsystems 2, components R1/R3, audio-engine 1, control-packages 1, convex-api 1, native 3/4.

### B4. One wire contract for TS and C++
`packages/desktop-protocol` owns every host protocol fact (version, magic, artifact id, control types, status enums, limits, header sizes, capability bits, page size, spool states, refusal codes, host-lost as a typed reply). The generator emits the C++ header; TS decoders become table lookups; contract package exports decoders next to encoders; shared limits/patterns module (`maxVstStateBytes`, `sha256HexSchema`, ...) replaces literal copies; JS worker constants come from one module.
- native 1/5/7, src-lib-desktop 2, desktop-app 4, audio-engine 2/4, control-packages 4, cross-cutting duplicated vocabularies. Decide the mapped-range 256 vs 4096 mismatch first (native report).

### B5. Small shared primitives that replace scattered special cases
- Persisted-preferences / project-storage helper (key, schema, default, clamp) with `DEFAULT_BPM`, `clampBpm`, loop and grid defaults defined once. (src-lib-core 5, hooks-routes 5)
- Runtime environment module (`isDesktopRenderer`, `desktopBridge()`, `isMacDesktop`) and desktop env-flag registry. (hooks-routes 7, desktop-app 7)
- URL-state owner (no synthetic popstate). (hooks-routes 4)
- Retry/backoff + abortable sleep; `bestEffort(promise, reason)`; `safeDisconnect` for Web Audio; keyed async lock with order in the type. (src-lib-core 6/9, desktop-app 10, audio-engine 6)
- Typed renderer sender policy in desktop main. (desktop-app 2)

### B6. Operation tables
- User actions as commands (id, label, shortcut, run, enabled) driving toolbar, keyboard, desktop application menu, menu protocol. (components R4, hooks-routes 2)
- Desktop IPC operations declared once (channel, schema, handler, reply) for main, preload and the bridge type. (desktop-app 1)
- Control operation catalog drives sdk, cli, mcp and desktop-protocol maps; planner uses control's canonical JSON and digests; V2 derived from V1. (control-packages 2/3/5/6/8/9)
- Attached-host controller as an operation table with one mounted check. (src-lib-desktop 4)

### B7. Convex and API boundaries
Validators module, one project-edit boundary that advances the revision once, client/server mutation twins collapsed into one per operation with an operation table, typed `ConvexError` codes instead of message matching, `api/http` edge module, worker identity in one module, schema-driven project cascade, one retention helper, option-bag DI replaced by boundary fakes in tests. (convex-api 1-10)

### B8. Undo history as one table per entry type
`{ validate, apply, persist, merge }` per entry kind; persisted format unchanged (fixtures compared first). (src-lib-subsystems 1)

### B9. One project backend (local or cloud) chosen once per project
Replaces 110 `isLocalId` hook forks, 24 lib forks, direct Convex calls in hooks and raw `/api` fetches. Per mutation family, with durability per operation decided explicitly. (hooks-routes 1, src-lib-core 2)

### B10. Split god-modules by owner (move first, then change)
apps/desktop `main.ts` (control socket, renderer session, audio session, window) and `audio-host.ts` wire layer; AudioEngine facades instead of 42 pass-throughs; one effect-chain runtime for track and master; export job phases; shared-outbox transport vs feature handlers; OPFS session store; recording worker session; sampled-instrument preparation core; local-project row kinds; preferences migration table; plugin-catalog owner; outcome-typed async UI actions; device knob wrapper for plain effects. (desktop-app 3/5/8/9, audio-engine 3/5/7/9, src-lib-subsystems 3/4/5/7/8, src-lib-core 3/4, components R2/R5/R7)

### B11. Certification-anchored hot files (survey their bodies fresh first)
Publication runner out of `native-playback-controller.ts`, narrow slice interfaces, observer instead of `mark` threading; playback backend state machine in `useTimelinePlayback.ts`; `portable-browser-playback-controller.ts` split. Each needs an anchor-mode rebase. (src-lib-desktop 3/5, hooks-routes 3, src-lib-core 8)

### B12. Native C++ splits
`audio-host.cpp` and `audio_core.cpp` by responsibility, test hooks replaced by injected interfaces, fixed-layout records described once. (native 2/6) Survey function bodies first.

### B13. Comments (after code has moved)
Remove restating comments; replace pointers to documents not in the code ("design 1.3", "rule 0", C++ line numbers) with the rule itself; keep external-constraint comments. (every report §4, src-lib-desktop 6)

### B14. Tests (last)
Remove tests that repeat the implementation or cannot fail, rewrite tests tied to internals against behavior (including the `bun test` wrapper tests, the hand-replaced `globalThis.window` sites, copied agent-browser spawn helpers, substring tests that pin constants). (every report §5)

### Then: step 5 re-surveys until nothing worth fixing remains; behavior check (all tests, FAST-CERT, packaged app song playback/export).
