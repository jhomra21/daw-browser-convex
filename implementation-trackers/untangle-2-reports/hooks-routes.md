# Untangle step 2: src/hooks, context, routes, types, workers, main.tsx

Area: `src/hooks/**` (105 files; 68 non-test, ~25K lines), `src/context/**`, `src/routes/**`, `src/types/**`, `src/workers/**`, `src/main.tsx`. Read-only pass at HEAD `4223c4a2`. Co-change evidence from `git log -n 400 -- <area>` (400 commits touched the area).

## 1. Area summary

- `src/hooks` is not a set of generic hooks. It is the timeline controller layer: `Timeline.tsx` (components) wires ~60 `useTimeline*` hooks that each own a slice of one workflow (playback, recording, clips, tracks, automation, mixer, history, browser, MIDI, import, persistence, project route/data).
- Biggest modules: `useTimelinePlayback.ts` 2287 lines (transport + native/portable/legacy backends + recovery + rebuild queue; 83 top-level closures, 31 `setActiveBackend`/31 `requiresNativeAudio` uses); `useTrackRecording.ts` 1501; `useTimelineAutomationController.ts` 1250; `useTimelineBrowserController.ts` 1043; `useTimelineMixerController.ts` 1003; `useTimelineActions.ts` 880; `useTimelineClipActions.ts` 786.
- Extracted siblings of playback: `playback-audio-lifecycle.ts`, `playback-session-reconciliation.ts`, `deferred-stretch.ts`, `spectrum-frame-delivery.ts`, `timeline-playback-types.ts`. Recording split: `useTrackRecording`, `useMidiTrackRecording`, `recording-dispatch.ts`.
- Persistence primitive: `useProjectPersistedState.ts` (used by Preferences, LocalMix, ProjectMix, AutomationController only).
- `src/context`: `app-preferences.tsx` (Solid store + theme/audio side effects), `midi-access.tsx`, `export.tsx`. `src/routes`: `index.tsx` (project/dashboard URL state), `Login.tsx`, `about.tsx`, `oauth/consent.tsx`, `dsp-characterization.tsx` (diagnostic), `__root.tsx`. `src/types`: `desktop-bridge.ts` (the whole Electron preload contract, 379 lines, also imported by `apps/desktop/preload.ts` and tools), two `.d.ts` shims. `src/workers/recording-writer-worker.ts` (13 lines, thin shell over `lib/recording`).
- Dependencies in: components (Timeline.tsx, dashboard, TransportControls), `lib/desktop/*`, `lib/midi`, `lib/export`, `lib/project-save-status`, `apps/desktop/preload.ts`, tools/acceptance. Dependencies out: `~/lib/*` (almost everything), `convexClient`/`convexApi` (15 hook files), raw `fetch('/api/...')`, `window.dawDesktop`, `localStorage`, and 13 imports from `~/components/**`.
- Dominant structural fact: **110 `isLocalId('project', …)` branches in 26 hook files** choose between a local repository path and a cloud (convex/shared-operation/fetch) path inside each hook. This is the single biggest hidden link in the area.
