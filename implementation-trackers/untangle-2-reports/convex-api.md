# Untangle step 2: convex/** and api/** (read-only findings)

Repo HEAD `4223c4a2`, branch `anti-slop-update`. Nothing in the repo was edited, built or run. Scratch scripts are in `/tmp/untangle2/scratch/convex-api/` (`dead.py`, `unusedfn3.py`, `co.py`, `co2.py`).
Method: skeleton of exports/signatures for all ~100 files, full reads of the modules named below, `rg` across src/packages/apps/convex/api/tools for importers, `git log --name-only -n 400` for co-change.

## 1. Area summary

- **Convex backend** (`convex/`, ~15.9K non-test lines). `schema.ts` (25 tables, all keyed by a string `projectId`). Three very large domain modules each mix *Convex function registrations* with *row-level writers* that other modules import: `tracks.ts` (2330 lines), `clips.ts` (1937), `effects.ts` (1762). Smaller domains: `automation.ts`, `assets.ts`, `resumableAssetUploads.ts` (1130), `projects.ts`, `projectMixerSettings.ts`, `mixerChannels.ts`, `cloudBackups.ts`, `shareInvites.ts`, `r2Deletes.ts`, `exports.ts`, `sharedChat.ts`, `timeline.ts`.
- **Access layer**: `projectAccess.ts` (roles, identity claims), `trackWrites.ts`/`clipWrites.ts` (ownership + write access), `projectRows.ts` (project row + `withProjectEdit` revision stamping), `sharedOperationResults.ts` (idempotent operation replay).
- **Control platform** (public agent/CLI/MCP contract): `control.ts` (preview/approval/commit/history/recoveries), `controlPreflight.ts`, `controlExecution.ts` (a switch over every control action that calls the row writers in the domain modules), `controlRecovery.ts` (1562 lines), `controlSnapshot.ts`, plus shims `controlProjection.ts`, `controlEffectiveValues.ts`, `trackRouting.ts`, `assetFolders.ts`, `samples.ts`.
- **Hono API** (`api/`, ~5.7K non-test lines, excluding the 7.7K generated `worker-configuration.d.ts`): `index.ts` (CORS, session middleware, route registration), `routes/*` (control REST, MCP, samples, resumable uploads, cloud backups, exports, share invites, timeline operations, maintenance), `control-oauth.ts` (OAuth provider layer with raw D1 SQL), `convex-auth.ts` (mints JWTs for Convex incl. `dawWorker` and actor claims), `timeline-operation-executor.ts` (shared timeline op kind -> `server*` Convex mutation), `r2-delete-queue.ts`, `default-samples.ts`, `control-upload-audio-metadata.ts`, `resumable-sha256.ts`.
- **Dependencies in**: src/ calls only a few client mutations directly (`tracks.remove`, `clips.move`, `clips.setTiming*`, `effects.listByRoom`, ...); almost all writes go `src -> /api/projects/:id/timeline/operations -> executeTimelineOperation -> server* mutation`. **Out**: `@daw-browser/shared`, `control`, `control-core`, `timeline-core`. api imports `convex/_generated/api` and `convex/schema` (tests only).
- **Churn** (git, 167 commits touching convex/ or api/, `co.py`): `schema.ts` 53, `effects.ts` 51, `tracks.ts` 51, `clips.ts` 37, `api/timeline-operation-executor.ts` 32, `api/index.ts` 30, `projects.ts` 30. Strongest pairs: effects+tracks 21, schema+tracks 20, schema+clips 20, executor+effects 19.
- Prior pass (PR #62 plan, Track X, P21 "a project edit owns its revision stamp"): **partly done** (`withProjectEdit` exists at `convex/projectRows.ts:42` and is used by effects/control/createTrack). It did not touch the 55 other revision-advance sites (H4) and `effects.ts:367`'s `revision ?? 0` sentinel is deliberately kept (not re-listed as a problem).
